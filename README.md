## Publish on GitHub Pages

1. Extract the ZIP archive.
2. Upload the **contents** of the archive, including the `assets` folder, to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`.
4. Visit https://markoshelps.github.io/viator-deals-and-discounts/ and refresh after deployment.
