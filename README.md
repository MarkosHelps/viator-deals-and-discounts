# Viator Deals & Travel Experiences 2026–2027

A modern, responsive **Viator-inspired travel discovery page** for GitHub Pages, built from the supplied TheSmart.Deals Viator article.

![Travel banner](assets/banner.svg)

## Features

- 36 travel and activity links grouped into five collections
- Responsive teal-and-mint design with an included local SVG banner
- Live client-side search
- Accessible navigation, FAQ and clear booking links
- Lightweight static HTML, CSS and JavaScript (no build tools needed)
- Independent affiliate disclosure in the footer

## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `viator-deals-and-discounts`.
2. Upload **all files and the `assets/` folder** from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish the site.

The landing page is `index.html`. All styling, scripts and banner assets are included locally. No setup or dependencies are required.
