## ⚙️ GitHub Pages Deployment

The website can be published directly through GitHub Pages.

1. Open your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the **main** branch.
5. Select **/(root)** as the publishing directory.
6. Click **Save**.

Your website will be available at:

**https://markoshelps.github.io/viator-deals-and-discounts/**

### Local Preview

Clone the repository:

```bash
git clone https://github.com/markoshelps/viator-deals-and-discounts.git
```

Open the project directory and launch `index.html` in your browser.
